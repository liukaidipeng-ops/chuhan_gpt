## 3. 设计、技术标准与验收

- 史笔方向、2.39:1 宽银幕、偏暖黎明/黄昏、胶片颗粒、景深与有表演的高精度角色。虞姬用剪影，项羽黑披风少红；这些有历史批准依据。
- 江与江东在画左，汉军从画右/身后逼近；摄影与人物关系保持轴线连续。每次切镜要有叙事或表演理由，避免为切而切。
- v3 复盘建议约 11 镜、55～60 秒、纵深长镜头，先构图定格获认可再拍运动。这是部门拟定改法，不冒充已获用户逐项批准的最终分镜。
- 用户要求镜头和表演节奏优先于音效；允许临时配音占位。复盘提出台词 atempo 1.2～1.3 倍、镜尾 0.3～0.5 秒，仍需用实际试听和画面验证。
- 影片接口：FILM[id]() 返回 ctx、cam、post、dur、update(t,dt)；film.py 用固定步长和 SB.shoot 逐帧输出，24 fps，默认宽 1280，高度按 2.39 比例取偶数。依赖已构建游戏页、Playwright、Pillow、对应 CG 资产。
- assemble2.py 输出 1280×720、上下黑边 92 像素；H.264/AAC、yuv420p、faststart，帧来自各镜头目录。缺帧时会复用末帧，因此“能拼片”不等于没有冻结画面，交付须查帧数、动作连续和音画时长。
- TD H1 提出 mp4 尽量 ≤15 MB、按需下载、进度、跳过、失败/超时回原流程、移动端 playsinline 和声音启动兼容。它是接入要求/建议，不是本次实测兼容结论。
- 优化部实时三维草案为 ≤200 draw calls、≤60 万三角形，主角 ≤3 万三角形/6 网格/60 骨骼，贴图通常 ≤1024、脸可一张 2048、独立包 ≤3 MB。不得混同为已选预渲染 mp4 的 3 MB 限额；若重议实时路线再与优化部核预算。
- 字幕片名字体依据 G1 回话使用 songhei-subset.woff2；朱 #a8281c、米白 #f0e7d2、墨 #141311。本次未独立读美术总监原始回话，证据层级为 G1 留存转述。
- 后续验收：逐镜定格构图/穿模/轴线；抽帧与动态检查下马、交缰、回头；检查台词变速音质与字幕同步；成片规格和尺寸；由 TD 验证胜负、和棋、主帅阵亡、主动跳过、下载失败、返回大厅/再来一局/复盘的结局衔接。手机竖屏最终展示选项仍待核实，不能自行声称已定具体方案。
