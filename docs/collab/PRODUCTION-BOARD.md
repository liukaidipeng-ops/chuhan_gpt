用户只需填写“用户优先级”列。可用值：`P0`、`P1`、`P2`、`P3`、`HOLD`。空白表示待排序。

## 使用规则

1. 所有部门的新任务、衍生任务和预计任务先报总协调。
2. 总协调去重、拆依赖、补齐验收条件后录入本表。
3. 用户填写优先级；需要方案选择时，材料进入审批台。
4. 总协调按优先级正式下发；部门不得自行改顺序。
5. 部门回报完成、阻碍、缺项和新增范围；总协调持续巡检漏项、少做和发呆。
