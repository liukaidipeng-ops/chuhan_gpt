# 部署补丁：release-r12（动态预算版新霸王，供实测）

> 分支：`ai/rel-r11`（基于 **main = 线上 2026.10.22-845ec5 线**，带预想接口）
> 默认 = **r12 动态预算版**（开局不变慢、随局面逐步加，最多 2.17×）；**未合并 main**，等用户实测拍板。

## 0. 线上真实基准（先看）
- 线上 `LEVELS.hard = { budget: 3000, dyn: 2.7 }` → 平时≈3s/步，难局最多≈8.1s；`xhard`=9000。
- 本补丁的 r12 动态曲线：**1–5 回合保持 3000ms（开局不变慢）**；6→13 回合线性升到 **6500ms**（2.17×）；≥13 回合封顶 6500ms。
- ⚠️ 动态版**关掉了原 dyn 的 2.7× 再放大**（否则 6500×2.7 会飙到 17s+，手感不可控）；曲线本身就承担“难局多想”。
- 最坏单步：第 3 层兜底为 2×当前预算 → 后段最坏约 **13s**（实测 5 局自对弈后段 max 13.5s）；平均远低于上限（简单局面提前收手）。

## 1. 改了什么
1. `source/src/bfai.js`（默认 = 动态版）：
   - **保留 main 全部能力**：预想接口（ponderStart/Move/Stop/Info）、MCAP、T6、TTD、BMH、PVS、SPEND、C70/C71/C72；
   - **r11 五项修法**：CAPTIE / SPD / PUPD / UPQ / DPNT + 打开 r4 系开关（ATKUP/CAPUP/UP3L/CAPUP2）；
   - **r12 动态预算曲线**（BFAI_DYN2）：按回合 1.0→2.17×，带复杂度修正（残子≤20 / 军功和≥30 / 有 lv≥3 子 → 各 +4%，封顶 ×1.12）；**节点制（考卷/裁判）完全跳过**。
2. 备用文件（`source/docs/deploy/rel-r11/`）：
   - `bfai-p4500.js`：固定 4500ms（线上 1.5×，中间档）
   - `bfai-p6500.js`：固定 6500ms（线上 2.17×，静态满档，等效 r12 后段上限）
   - `bfai-r11s.js`：固定 6500 + 提速 getter ×1.48（有效≈9620ms，线上 3.2×，最慢档）
   - 切换 = 用对应文件覆盖 `source/src/bfai.js` → `cd source && node build.js`。

## 2. 实测曲线（r12 动态版；自对弈 5 局，base 3000）
| 回合 | 预算上限 | 实测平均 | p90 |
|---|---|---|---|
| 1–5（开局） | 3000ms | **2.29s** | 4.80s |
| 6–10（中局） | 3.4–5.2s | **3.27s** | 5.68s |
| 11–16（中后） | 5.2–6.5s | **4.09s** | 6.79s |
| 17+（后段） | 6500ms | **4.60s** | 8.02s |
- 简单局面会提前算完（平均低于上限）；复杂局面才用满 6.5s → “先简单后难”的手感。
- 节点制考卷：**198/198 不退化**（动态逻辑在节点制下跳过）。

## 5. 预想接口无冲突 / maxMs 说明
- 预想实现在 `bfai.js`（ponderStart/Move/Stop/Info + think 的 opt.ctl）；main.js 只接线。
- r12 动态只改 `L.budget`；预想期间 ctl 会覆盖 deadline/nodeCap（动态放大对预想无效，安全）。
- 旧 `min(budget×k,5000)` 已改 `max(base,min(base×k,cap))`，大档位不会被砍。
- `maxMs`（计时模式）保持 main 原样：**普通人机不传 maxMs，动态 6500 不会被砍**；开计时/联机替补 AI 时按钟保护（maxMs/3.5 与 0.75×maxMs 硬截止），属期望行为。

## 6. 实测口径（诚实版）
- **对真线上 3000ms 的纯 AI 增量（同时间）**：P30 正式 600 局 = **57.0%（95% 53.1–60.9）**（run #40153826954）。
- 对 r1 同条件 48.8%、6.5s+预想 49.8%（认证线 <60%，单列）。
- live 5s 口径 65.7%（600 局）为 lab 配置口径（旧侧 6500 预算，不等于真线上）。
- r12 动态档对真线上的正式对打在跑（`t5-r12-dyn-a/b`，seeds 103000/104000），出数后补。
